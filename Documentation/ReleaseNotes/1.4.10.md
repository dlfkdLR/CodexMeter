# CodexMeter 1.4.10

A small polish on the menu bar diamond.

## What changed

- **The diamond's fill eases to a new level instead of snapping.** When the tightest account limit ticks down between refreshes, the diamond now drains toward the new level over about half a second rather than jumping. Reduce Motion still snaps.

No preference or data changes.

## Verification

- 297 automated tests, 0 failures (8 environment-integration tests skipped); `DiamondMeterIconTests` render the meter through `ImageRenderer` and check that a fuller diamond draws more ink.
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy dlfkdLR/tap/codexmeter
```

For a new installation:

```bash
brew install --cask dlfkdLR/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `dlfkdLR/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.4.10.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.4.10.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.4.10.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
