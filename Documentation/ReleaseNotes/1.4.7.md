# CodexMeter 1.4.7

A bug-fix release for the software-update flow.

## What changed

- **The "An error occurred while launching the installer" update failure now has a way out.** It happens when an earlier automatic update already placed a newer build on disk while this older copy keeps running — Sparkle then can't install over it, and the dialog's only button was "Cancel Update". CodexMeter now detects that situation (before the check, or when Sparkle aborts the install) and offers **Restart Now**, which quits the stale process and reopens the app so the pending update applies. Nothing needs to be reinstalled.
- The takeover is scoped to that one recoverable case. Genuine install failures — no write permission to the Applications folder, a full disk, a cancelled authorization prompt — keep Sparkle's own accurate message. A background scheduled check that fails never pops an unsolicited dialog. If the automatic relaunch can't be started, CodexMeter explains how to quit and reopen manually instead of leaving you with no running app.

No change to the update feed, the signing keys, automatic-update behavior, or the check schedule.

## Verification

- 292 automated tests, 0 failures (7 environment-integration tests skipped); new coverage for the on-disk replacement detection and the error-code scoping.
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy dlfkdLR/tap/codexmeter
```

For a new installation:

```bash
brew install --cask dlfkdLR/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `dlfkdLR/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.4.7.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.4.7.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.4.7.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
