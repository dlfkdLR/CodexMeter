# CodexMeter 1.4.9

The menu bar diamond becomes a meter.

## What changed

- **The menu bar diamond now fills from the bottom to show how much account limit is left.** It tracks the tightest limit window for the selected provider — Codex's app-server limits, or Claude's five-hour / weekly — so a full diamond means fresh quota and a near-empty one means the limit is close. When there is no limit snapshot (limits turned off, still loading, unavailable, or Claude not connected) it shows the outline alone, as before. The mark still tints with the menu bar appearance and highlight.

No preference or data changes.

## Verification

- 298 automated tests, 0 failures (8 environment-integration tests skipped); new `DiamondMeterIconTests` cover the tightest-window selection, out-of-range clamping, the template-image flag, and a pixel-coverage check that a fuller diamond draws more ink.
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy dlfkdLR/tap/codexmeter
```

For a new installation:

```bash
brew install --cask dlfkdLR/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `dlfkdLR/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.4.9.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.4.9.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.4.9.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
