# CodexMeter 2.0.0

**The menu bar is gone.** CodexMeter is now a floating **edge notch** — a usage
ring per provider welded to a screen edge — plus a Settings window, with a small
status-bar item as the way in. The notch, its session awareness, threshold
alerts, and the extra provider adapters are ported from the MIT-licensed
[Codenotch](https://github.com/vinzdg/codenotch); see `NOTICE`.

This is a breaking change to how you interact with the app. Your data,
preferences, saved Codex accounts, and Claude connection are untouched.

## What changed

### Removed

- **The `MenuBarExtra` popover, its diamond meter, and the token-count menu-bar
  text.** The readings live in the notch and in **Settings ▸ Usage** now.
- The **Menu Bar** settings pane. Number format and the cached-input /
  last-updated toggles moved to **Settings ▸ General ▸ Usage Numbers**. The
  `menuBarDisplay` / `showMenuBarIcon` / `showMenuBarText` / `menuBarPeriod`
  preferences no longer do anything.

### Added

- **Edge notch.** A ring per provider — Codex, Claude Code, and any of GitHub
  Copilot, Cursor, Grok, OpenCode, Command Code, GLM (Z.ai), or Ollama Cloud
  whose CLI or editor is signed in on this Mac. Hover to expand for the limit
  tooltip; ⌥-drag to slide it along the edge; the gear orb opens Settings.
  **Off by default** — turn it on from the status-bar menu's *Show Notch* or in
  **Settings ▸ Notch**.
- **Session awareness.** A working agent spins its ring; one blocked waiting on
  your input pulses amber; when a session finishes the notch drops open for five
  seconds — click that peek to raise the terminal it was running in. Optionally
  plays a sound. Reads local session files only.
- **Limit alerts.** A macOS notification when a provider's headline limit
  crosses 80%, then 100% — once per crossing, and again only after the window
  resets. Per-provider mute.
- **"Notch" and "Usage" settings panes.** Notch: pinned-open vs show-on-hover,
  size, ring colour, reset-time wording, a usage-pace line, and the session /
  alert controls. Usage: the token history, day/week/month charts, and the
  project and session breakdowns the popover used to show — including the Codex
  account switcher at the top.
- **Status-bar menu.** *Show Notch*, *Usage…*, *Settings…*, *Check for Updates…*,
  *Quit* — always present, since the popover is gone.

### The borrowed-credential providers

The seven non-Codex/Claude rings read a credential the owning CLI or editor
already holds — `gh auth token`, Cursor's `state.vscdb`, `~/.grok/auth.json`,
`~/.local/share/opencode/auth.json`, `~/.commandcode/auth.json`, a Z.ai plan key
in a coding tool's config, or `OLLAMA_API_KEY`. CodexMeter stores none of them,
and a ring appears only when its credential is present. (Antigravity and the
`cursor-agent` / Settings-key paths for Cursor and Ollama are not in 2.0.)

## Updating from 1.x

The in-app updater carries you across: `CFBundleVersion` jumps from `1410` to
`20000` (the old `major.minor.patch` → digits scheme would have made `2.0.0`
read as *older* than `1.4.10` and broken the update). After updating, the
menu-bar diamond is replaced by the status-bar item; open its menu and choose
**Show Notch** if you want the ring.

  Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy dlfkdLR/tap/codexmeter
```

For a new installation:

```bash
brew install --cask dlfkdLR/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it
came from `dlfkdLR/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-2.0.0.dmg` and `SHA256SUMS.txt` from this release into the
same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.0.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.0.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and
use the app-scoped quarantine command above.

## Recovery

This release does not migrate any database. Published version tags are
immutable; corrections ship as a new patch release.
