# CodexMeter 2.0.2

Small notch additions.

## What changed

- **Local Ollama models.** When `ollama serve` is running, the notch shows a
  cell with how many models are loaded, and the tooltip lists them by name and
  resident memory. It is not a ring — a local model server has no quota. No
  daemon, or nothing loaded, means no cell.
- **Limit-alert mute is per provider.** The 80% / 100% notification can now be
  muted for any of the notch's ten quota providers, not just Codex and Claude —
  see **Settings ▸ Notch ▸ Limit Alerts**.

## Verification

- 592 automated tests, 0 failures (9 environment-integration tests skipped).
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later.
- Ad-hoc signed, not Apple-notarized. SHA-256 protects the first download;
  Sparkle authenticates later updates with Ed25519 signatures.


```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app

```

## First direct-download launch

Download `CodexMeter-2.0.2.dmg` and `SHA256SUMS.txt` into the same folder and
verify the checksum before opening:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.2.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.2.dmg
```
