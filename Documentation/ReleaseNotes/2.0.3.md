# CodexMeter 2.0.3

Every notch provider is now a Settings entry, with its usage in view.

## What changed

- **All notch providers in Settings.** The **Settings ▸ Providers** list used to
  stop at Codex and Claude Code. It now includes GitHub Copilot, Cursor, Grok,
  OpenCode, Command Code, GLM, Ollama Cloud, and Antigravity — each with a green
  dot when connected and an "N on" count on the header.
- **Usage without opening the notch.** Each borrowed-credential provider's pane,
  modelled on Codenotch's account row, shows its live limit windows as labelled
  bars (% used / left, reset time), today's local token total where CodexMeter
  meters it, any active block, the account the reading is borrowed from, and a
  per-provider 80% / 100% alert mute. "Allow access…" appears only when macOS
  actually refused the credential.
- Codex and Claude Code keep their fuller panes — they are metered locally.

## Verification

- 592 automated tests, 0 failures (9 environment-integration tests skipped).
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later.
- Ad-hoc signed, not Apple-notarized. SHA-256 protects the first download;
  Sparkle authenticates later updates with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy dlfkdLR/tap/codexmeter
```

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-2.0.3.dmg` and `SHA256SUMS.txt` into the same folder and
verify the checksum before opening:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.3.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.3.dmg
```
