# CodexMeter 2.0.4

Settings ▸ Providers, rebuilt as one list.

## What changed

- **One Providers pane, not a sidebar row each.** Modelled on Codenotch's
  account list: a **Connected** group whose rows drag to reorder the notch
  rings, and a **Not connected** group of sign-in prompts. Each row shows the
  account the reading is borrowed from, an inline 80% / 100% mute bell, and a
  single action — **Details** for Codex and Claude Code, **Allow Access…** when
  macOS refused a saved login, **Open <app>** otherwise. Details drills into the
  fuller pane in place.
- The per-provider limit-alert mutes moved off the Notch pane onto their rows.
- The **Usage** pane no longer leaves a bare void beside its column in a wide
  window — the reading column is centred with the pane painted behind it.

## Verification

- 592 automated tests, 0 failures (9 environment-integration tests skipped).
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later.
- Ad-hoc signed, not Apple-notarized. SHA-256 protects the first download;
  Sparkle authenticates later updates with Ed25519 signatures.

## First direct-download launch

Download `CodexMeter-2.0.4.dmg` and `SHA256SUMS.txt` into the same folder and
verify the checksum before opening:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.4.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.4.dmg
```
