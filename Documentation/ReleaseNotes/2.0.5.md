# CodexMeter 2.0.5

Two fixes from a Homebrew install of 2.0.4.

## What changed

- **The Claude limits helper is no longer blocked on a Homebrew install.**
  Homebrew quarantines the app bundle; the helper CodexMeter deploys for Claude
  Code's status line inherited that flag and macOS refused to run it ("cannot be
  opened because Apple cannot check it for malicious software"). CodexMeter now
  clears the flag from the copy it writes — on this launch, and self-healing on
  the next one for anyone already affected.
- **The Usage pane no longer leaves a wide empty gap beside its column.** The
  reading column sits against the leading edge like every other pane, with the
  pane painted behind it.

## Verification

- 593 automated tests, 0 failures (9 environment-integration tests skipped).
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later.
- Ad-hoc signed, not Apple-notarized. SHA-256 protects the first download;
  Sparkle authenticates later updates with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy dlfkdLR/tap/codexmeter
```

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-2.0.5.dmg` and `SHA256SUMS.txt` into the same folder and
verify the checksum before opening:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.5.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.5.dmg
```
