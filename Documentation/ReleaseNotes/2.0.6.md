# CodexMeter 2.0.6

Follow-up fixes from a review of the new Providers pane.

## What changed

- **The Providers pane no longer stutters.** It was reading each provider's
  borrowed account — for Cursor and a few others, opening a file or a SQLite
  database — on every redraw. Those reads are cached now and refreshed on a
  fetch, not on a render.
- **Provider rows keep a stable order** rather than occasionally reshuffling the
  ones you have not dragged.
- **Toggling an alert mute, or dragging a provider, no longer starts a
  Codex-limits network fetch.** The limits poll only restarts when the
  account-limits setting itself changes.

## Verification

- 594 automated tests, 0 failures (9 environment-integration tests skipped).
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later.
- Ad-hoc signed, not Apple-notarized. SHA-256 protects the first download;
  Sparkle authenticates later updates with Ed25519 signatures.

## First direct-download launch

Download `CodexMeter-2.0.6.dmg` and `SHA256SUMS.txt` into the same folder and
verify the checksum before opening:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.6.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.6.dmg
```
