# CodexMeter 2.0.7

Limit readings that say the truth once, and a Settings window that opens.

## What changed

- **The same limit is no longer drawn twice.** Every window of a provider
  shared one identifier, so the notch tooltip rendered the first one once per
  duplicate — the "Weekly / Weekly" and "5 hours / 5 hours" pairs, identical
  down to the reset time.
- **Two limit groups no longer share a label.** Codex meters a per-model
  allowance beside the plan's own and both printed as "5 hours"; a row now
  names its group when there is more than one.
- **ChatGPT Pro's phantom five hours is gone.** Pro has only the weekly
  allowance, but the app-server reports a five-hour window anyway — with a
  reset that is not five hours away. Hidden for Pro accounts and nobody else.
- **Settings opens.** An accessory app is restricted from activating its own
  windows, so "Settings…" could look like it did nothing. It now comes forward
  reliably, and re-centres if it was left on a display that is gone.
- **The notch is on by default.** A first launch showing nothing but a
  status-bar glyph does not look like a working app.
- **Settings rebuilt** — tinted icon badges in the sidebar, panes made of
  grouped rounded cards, in the shape macOS System Settings uses. The settings
  search field is gone.

## Verification

- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later.

```

```

## First direct-download launch

Download `CodexMeter-2.0.7.dmg` and `SHA256SUMS.txt` into the same folder and
verify the checksum before opening:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.7.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.7.dmg
```
