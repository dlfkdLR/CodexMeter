# CodexMeter 2.0.8

The Pro fix from 2.0.7, working this time.

## What changed

- **ChatGPT Pro's phantom five-hour window is actually hidden now.** 2.0.7 read
  your plan from the account saved inside CodexMeter — which is empty unless you
  explicitly added one, so for most people the plan came back unknown and the
  window stayed on screen. It now reads the plan from the Codex login you are
  actually signed in with.

## Verification

- 600 automated tests, 0 failures (9 environment-integration tests skipped).
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later.
- Ad-hoc signed, not Apple-notarized. SHA-256 protects the first download;
  Sparkle authenticates later updates with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy dlfkdLR/tap/codexmeter
```

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-2.0.8.dmg` and `SHA256SUMS.txt` into the same folder and
verify the checksum before opening:

```bash
cd ~/Downloads
grep ' CodexMeter-2.0.8.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-2.0.8.dmg
```
